description: The page builder, which makes of a Markdown file a page the living reads.
dependencies: []
---

A source is a Markdown file. Its front matter names its page type, and the builder publishes it as that type.

```ethos
PageType.[ Plain
           NewModule
           ModuleEdit ]
```

A Plain page is Markdown that proposes nothing, shown as it is written; a file that names no type is Plain. A NewModule page is a whole new module, shown as its Markdown. A ModuleEdit page shows the changes to a landed module.

When a valid page fits no type, a type is added for it and the builder learns that type. The builder gains types and keeps the ones it has, so it does not change each time the way we work changes.

The builder publishes what it is given. What it finds amiss in a source, it reports beside the page.
