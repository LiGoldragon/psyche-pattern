---
description: The page builder, which makes of a Markdown file a page the living reads.
dependencies: []
---

A source is a Markdown file as it stands, front matter and all. The builder has no format of its own for a source: it reads the front matter and renders each field, the description in its box among them. The field `type` names the page type, and the builder publishes the page as that type.

```markdown
---
type: NewModule
---
```

```ethos
PageType.[ Plain
           NewModule
           ModuleEdit ]
```

A Plain page is Markdown that proposes nothing, shown as it is written; a file that names no type is Plain. A NewModule page is a whole new module, shown as its Markdown. A ModuleEdit source is the module as it would stand after the change. The builder compares it with the landed module and shows what is added and what is removed.

When a valid page fits no type, a type is added for it and the builder learns that type. The builder gains types and keeps the ones it has, so it does not change each time the way we work changes.

The builder publishes what it is given. What it finds amiss in a source, it reports beside the page.
