description: The fibers of a thread that writes code.
dependencies: []
---

They do the work that would fill the thread's context: searching and reading the code, running the tests, reading logs, and an edit that repeats across many files. A fiber runs on a cheap model and returns what the thread needs to know, in a few lines.

What has to be decided, the thread writes itself.

A fiber is kept through the thread's session and used again for the same kind of work.
